📤 How to upload this site to GitHub & enable Pages

  • 1 Create a new repository on GitHub (public or private). Do NOT add README yet.
  • 2 Clone or download this site: save the content as index.html (and optionally a README.md).
  • 3 In your local repo folder, add the file: git add index.html → git commit -m "Initial static site" → git push origin main.
  • 4 On GitHub repo → Settings → Pages → under "Branch" select main (or master) and /(root) → Save.
  • 5 After a minute, your site will be live at: https://<your-username>.github.io/<repo-name>/
✅ Pro tip: you can also drag & drop the index.html file directly into GitHub's web uploader. Enable Pages as above.
